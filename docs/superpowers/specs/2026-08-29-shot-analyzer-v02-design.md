# AI Basketball Shot Analyzer V0.2 设计

## 目标

把 V0.1 的单次二维姿态分析升级为连续投篮序列分析：自动切分每次投篮、评估拍摄质量和机位、使用篮球轨迹辅助出手时刻、增加实验性手部翻腕指标，并输出逐次片段、轨迹视频和跨次训练建议。

## 科学边界

- 单机位只能输出画面归一化坐标中的篮球轨迹和出手点，不能还原真实球场投篮位置。
- 翻腕角来自二维手部关键点，只用于同机位多次动作趋势，不作为职业标准或伤病判断。
- 篮球/手部检测不足时降级到 V0.1 的姿态规则，并在结果中显示方法与可信度。
- 连续投篮至少检测到两次才输出跨次一致性；单次视频仍可分析，但不声称具有重复性证据。

## 架构

1. `video_intelligence.py`：纯算法层，负责质量评分、轨迹平滑、球手分离出手候选、候选去重、投篮窗口切分、跨次统计。
2. `vision_models.py`：封装 MediaPipe Hand Landmarker 和 EfficientDet Lite0 Object Detector；模型加载失败不会终止姿态分析。
3. `pose_analyzer.py`：协调姿态、手部、篮球检测，记录逐帧数据，输出骨架+球轨迹视频、关键帧与逐次投篮片段。
4. `report_generator.py`：总体质量、机位修正、逐次指标、跨次一致性、完整训练计划。
5. `app.py`：V0.2 页面、质量卡片、投篮选择器、轨迹视频和切片下载。

## 出手与切分规则

- 首选：篮球靠近投篮手腕后开始持续远离，并具有向上速度，产生“球手分离”候选。
- 后备：最低点之后投篮手腕向上速度局部峰值。
- 候选相隔不足 0.8 秒时只保留证据更强者。
- 每个候选向前取约 1.2 秒、向后取约 0.9 秒，相邻窗口在中点截断。
- 没有可靠候选时退回单次全视频分析。

## 拍摄质量与机位

- 元数据：分辨率、FPS、时长。
- 画面：亮度、清晰度（拉普拉斯方差）。
- 姿态：有效帧率、全身入镜率、人体画面占比、侧面机位近似评分。
- 输出不是“自动几何校正后的伪精确角度”，而是可执行的重拍方向：增亮、固定相机、后退、降低/升高机位、转到投篮侧面。

## 手部与训练建议

- 投篮手通过与 Pose 手腕最近的 Hand Landmarker 结果匹配。
- 翻腕角定义为 `肘 → 手腕 → 中指 MCP` 的二维夹角。
- 随挥方向使用 `手腕 → 中指指尖` 的二维方向；只在出手与随挥附近手部有效时给数值。
- 训练建议围绕跨次标准差、球手分离时序、伸肘—翻腕顺序、手指随挥方向和下肢节奏，不规定唯一最佳角。

## 验收

- 单次视频保持兼容。
- 三次拼接测试至少得到两个以上投篮窗口，输出 `shot_01.mp4` 等片段。
- 输出包含 `trajectory_video.mp4`、逐帧 CSV、关键帧、逐次统计和 HTML 报告。
- 篮球或手部检测缺失时不崩溃，页面明确降级方法。
